# 🎮 Twitch Drop Miner для Wuthering Waves - Упрощенная версия

Упрощенная версия оригинального проекта [Twitch-Channel-Points-Miner-v2](https://github.com/Tkd-Alex/Twitch-Channel-Points-Miner-v2) специально для фарма дропов игры **Wuthering Waves**.

## 🌟 Особенности

- ✅ **Только дропы**: Удалены все ненужные функции (ставки, рейды, IRC чат)
- ✅ **Простота**: Всего 3 файла для легкого понимания и настройки
- ✅ **Многоаккаунтность**: Поддержка 5-10 аккаунтов одновременно
- ✅ **Русский язык**: Все логи и сообщения на русском языке
- ✅ **Автоматизация**: Автоматический поиск стримеров с дропами
- ✅ **Безопасность**: Сохранение cookies для избежания частых авторизаций

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка аккаунтов
Отредактируйте файл `config.py` и добавьте свои аккаунты:

```python
ACCOUNTS = [
    {
        "username": "ваш_логин_1",
        "password": "ваш_пароль_1",
        "enabled": True
    },
    {
        "username": "ваш_логин_2",
        "password": "ваш_пароль_2",
        "enabled": True
    },
    # Добавьте еще аккаунты по необходимости
]
```

### 3. Запуск
```bash
python main.py
```

## ⚙️ Настройки

### Настройки дропов (DROP_SETTINGS)
- `game_name`: Название игры (по умолчанию "Wuthering Waves")
- `auto_claim`: Автоматически забирать дропы (True/False)
- `check_interval`: Интервал проверки дропов в секундах
- `claim_from_inventory`: Забирать дропы из инвентаря при запуске

### Настройки стримеров (STREAMER_SETTINGS)
- `auto_discover`: Автоматически находить стримеров с дропами
- `manual_streamers`: Список конкретных стримеров для отслеживания
- `max_streamers`: Максимальное количество стримеров
- `priority_streamers`: Приоритетные стримеры

### Настройки логирования (LOGGING_SETTINGS)
- `level`: Уровень логирования (DEBUG/INFO/WARNING/ERROR)
- `save_to_file`: Сохранять логи в файл
- `console_output`: Выводить логи в консоль
- `show_emoji`: Показывать эмодзи в логах

## 🔧 Как это работает

1. **Авторизация**: Программа авторизуется во всех активных аккаунтах
2. **Поиск стримеров**: Автоматически находит стримеров, которые стримят Wuthering Waves с дропами
3. **Просмотр**: Симулирует просмотр стримов для накопления времени для дропов
4. **Получение дропов**: Автоматически забирает дропы когда набрано достаточно времени
5. **Мониторинг**: Отслеживает прогресс и переключается между стримерами

## 🚨 Важные замечания

1. **Безопасность**: Не делитесь своими логинами и паролями
2. **Лимиты**: Twitch позволяет смотреть только 2 канала одновременно на аккаунт
3. **Дропы**: Дропы начисляются только при просмотре стримеров с активными дропами
4. **Время**: Для получения дропов нужно определенное время просмотра (обычно 15-60 минут)

## 🔍 Поиск и устранение неисправностей

### Ошибки авторизации:
- Убедитесь, что логин и пароль правильные
- Проверьте, что аккаунт не заблокирован
- Попробуйте удалить файлы в папке `./cookies/`

### Не находятся стримеры:
- Убедитесь, что есть активные стримеры с дропами Wuthering Waves
- Проверьте правильность названия игры в настройках

### Не получаются дропы:
- Убедитесь, что аккаунт связан с игрой
- Проверьте, что дроп-кампания активна
- Убедитесь, что набрано достаточно времени просмотра

## 📝 Логи

Логи сохраняются в папке `./logs/` и выводятся в консоль. Уровень детализации можно настроить в `config.py`.
