# Twitch Drops Miner - Упрощенная версия

Упрощенная версия Twitch Channel Points Miner v2 для автоматического получения дропов с Twitch.

## Особенности

- ✅ Авторизация через twitch.tv/activate (без пароля)
- ✅ Поддержка до 20 аккаунтов одновременно
- ✅ Автоматическое получение дропов
- ✅ Консольный интерфейс на русском языке
- ✅ Простая настройка и использование
- ✅ Упрощенная структура проекта (1-3 файла)

## Установка

1. Установите Python 3.7+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

1. Запустите скрипт:
   ```bash
   python twitch_drops_miner.py
   ```

2. Добавьте аккаунты через меню "Управление аккаунтами"

3. Запустите мониторинг дропов

## Авторизация

Программа использует безопасную авторизацию через twitch.tv/activate:
1. Программа выдает код авторизации
2. Вы переходите по ссылке twitch.tv/activate
3. Вводите код авторизации
4. Готово! Аккаунт добавлен

## Настройки

- **Интервал проверки**: как часто проверять дропы (минимум 30 секунд)
- **Автоматическое получение**: автоматически получать готовые дропы
- **Время просмотра**: сколько времени "смотреть" стрим для дропов

## Функции

### Основные возможности:
- Добавление/удаление аккаунтов
- Мониторинг активных кампаний дропов
- Автоматическое получение дропов
- Обновление токенов авторизации
- Статистика и настройки

### Безопасность:
- Использует официальный Twitch API
- Не требует пароли
- Безопасная авторизация OAuth
- Соблюдает лимиты API

## Структура файлов
